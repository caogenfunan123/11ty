# Hello World

这是使用 **Eleventy** 搭建博客的第一篇文章，欢迎来到我的博客！

## 关于 Eleventy

Eleventy（11ty）是一个简单、灵活的静态网站生成器，特点包括：

- 零配置即可开始使用
- 支持多种模板语言（Liquid、Nunjucks、Markdown 等）
- 不依赖前端框架
- 构建速度快，输出纯静态 HTML

## 快速开始

你可以使用 Markdown 来编写文章，Eleventy 会自动将其转换为 HTML 页面。

```bash
npx eleventy
```
